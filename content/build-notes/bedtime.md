# Bedtime

**Description:** Flashing an AliExpress clock clone with ESPHome.

## Build log

- **2024-12-26 (approx):** Purchased clock from AliExpress (item 1005006159850972)
  - Link: https://www.aliexpress.com/item/1005006159850972.html
  - Video reference: https://www.youtube.com/watch?v=S1Q9PZ95SDM
  - Clone/lookalike version (not GeekMagic branded - saved $4)

- **2024-12-26:** Opened device
  - ESP8266 inside
  - No broken-out GPIO pins
  - Has TTL chip - visible when plugged into USB

- **2024-12-26:** Flashed with ESPHome via USB
  - Config from video worked immediately

- **2024-12-26:** Customised display
  - Displaying values from custom Zigbee2MQTT sensors
  - No issues
